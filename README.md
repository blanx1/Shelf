# Site Shelf

A list of my mini websites, hosted on GitHub Pages.

## Add a site

Edit `sites.json` on GitHub and add an entry. Separate entries with a comma, with no comma after the last one.

```json
{
  "name": "My New Site",
  "url": "https://example.com/",
  "category": "Projects",
  "description": "Optional short description."
}
```

Leave `url` as `""` for a site that isn't online yet. The page sorts and groups entries for you, so order doesn't matter.
